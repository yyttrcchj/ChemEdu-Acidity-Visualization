# Visual-teaching-research

This repository provides high-resolution visualization resources and computational data supporting research in **Chemistry Education**. It contains various theoretical descriptors and electronic structure analysis results designed for educational demonstrations and scientific communication.

## Project Structure

The repository is organized by theoretical analysis methods:

- **`ALIE/`**: Average Local Ionization Energy (ALIE) maps, used to identify sites for electrophilic attacks.
- **`CDFT/`**: Conceptual Density Functional Theory (CDFT) data, including Fukui functions ($f^+$, $f^-$, $f^0$) and dual descriptors.
- **`ESP/`**: Electrostatic Potential (ESP) surfaces, illustrating molecular polarity and interaction sites.
- **`HOMA/`**: Harmonic Oscillator Model of Aromaticity (HOMA) indices for evaluating aromatic character.
- **`IBSI/`**: Intrinsic Bond Strength Index (IBSI) files, detailing chemical bond stabilities.
- **`free_energy_calculation.txt`**: Detailed breakdown of thermodynamic property calculations.
